How it works: a Meshtastic device (Heltec / RAK / T-Beam …) on USB does the LoRa demod in hardware; the meshtastic Python API hands Ragnar the node DB + messages. MQTT is Meshtastic's Internet bridge — gateways publish mesh traffic to a broker (default the public mqtt.meshtastic.org), so ☁ MQTT streams the mesh worldwide with no node. The public channel key is well-known so its traffic is readable; private channels stay encrypted. The USB radio is used, so this doesn't contend for the RTL-SDR.
Send: a message goes out via your connected node's LoRa (real RF, licence-free ISM) when a node is connected, otherwise via MQTT (which needs a downlink-enabled gateway to reach RF). Map: GPS-positioned nodes are plotted relative to your node (self = green centre); MQTT-only stations show too. SNR colours the link.
