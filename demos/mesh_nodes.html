How it works: a Meshtastic device (Heltec / RAK / T-Beam …) on USB does the LoRa demodulation in hardware; the meshtastic Python API hands Ragnar the decoded node DB and messages. The public channel key is well-known so its traffic is readable; private channels stay encrypted. The device's own USB radio is used, so this does not contend for the RTL-SDR.
Map: nodes with a GPS position are plotted relative to your node (self = green centre). SNR colours the link. Nodes without GPS appear in the table only.
