This unit is the master: it pulls every Ragnar mesh unit's ADS-B, APRS, Meshtastic & ISM catch over the tailnet and merges it into one de-duplicated view. Each entity is keyed by its natural ID, so the same aircraft/station/node seen by several units is one row — tagged with who heard it.

How it works: the master GETs each peer's /api/mesh/sdr/<kind> snapshot over the tailnet (peer-readable, like the scan delegation) and merges by natural key — ICAO for aircraft, callsign for APRS, node id for Meshtastic, model+id for ISM. Duplicates collapse to one best report (positioned + freshest) with a heard-by list. No changes needed on the other units.
Coverage, not multilateration: this widens what you see by unioning every unit's catch — it does not compute positions from time-of-arrival (that needs precise synced clocks). Units at different locations add the most.
