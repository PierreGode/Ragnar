How it works: RF decode is rtl_fm | multimon-ng -a AFSK1200 — receive-only, no licence needed to listen. APRS-IS is a TCP client to the global network: a read-only login streams any region via a server filter; with your own callsign + passcode you get write access to send messages, which IGates relay to the recipient.
One dongle: RF APRS shares the RTL-SDR with the sweep / ADS-B / pager / VOR — starting one stops the others. APRS-IS is independent and keeps running. Legality: sending injects packets under your callsign on the ham network — only licensed operators should transmit/send. No RF transmit is performed here.
